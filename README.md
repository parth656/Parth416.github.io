## Publish with GitHub Pages

1. Keep the site entry point and required assets in the location expected by the repository's current structure.
2. Open **Settings → Pages** in GitHub.
3. Select the appropriate deployment source (branch/folder or GitHub Actions) based on the files in the repository.
4. Save the settings and wait for the deployment workflow to complete.
5. Open the published Pages URL and verify links, assets, and responsive behavior.

## Local preview

Inspect the repository to determine whether the site is plain HTML, a static-site generator, or a frontend build. For a plain static site, you can preview the root with:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

If the project uses a build tool, follow the commands in its dependency manifest instead.
